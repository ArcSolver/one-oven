# One Oven D1–D2 결과

작성일: 2026-10-15 KST. 범위: `one-oven/` 제품 백엔드(MCP 서버와 스케줄러).

## 만든 것

- 현재 폴더에 `git init -b main`. MIT LICENSE, 영어 README, lockfile 포함.
- 공식 TypeScript MCP SDK 1.32.1 기반 Streamable HTTP `/mcp`. 프로토콜 2025-11-25 초기화와 후속 헤더를 실제 클라이언트로 확인했다.
- 설계의 6개 툴: `set_kitchen`, `list_dishes`, `plan_meal`, `next_step`, `report_delay`, `swap_dish`.
- `dish://{id}`, `plan://{id}` 리소스와 목록/템플릿 조회. SQLite에 주방·계획·버전·단계 상태 저장.
- 모든 정상 툴 결과에 영어 `say`, `display`, ID 체인 제공. 실패는 `isError`로 반환하고 실패한 변경은 저장하지 않는다.
- 역산 리스트 스케줄러: 오븐별 동시 온도 범위 25°F 이하, 화구 수, 총 조리 인원 수, 요리별 선후 관계를 지킨다. `helpers: 1`은 본인 포함 한 사람이다.
- 원본 작성 타이밍 데이터 8개. D2 요구 4개를 넘겨 8요리 제약 테스트까지 구현했다. 실제 검증된 조리법이라는 뜻은 아니다.
- 완료/진행/대기 상태, 다음 단계 시작과 완료 확인, 지연 재계획, 미시작 요리 교체, 타이머 요청 문장.
- localhost 바인딩, SDK Host 검증, 외부 Origin 403. 외부 인증 없는 단일 가구 로컬용이다.

## 테스트 결과

실행 환경: macOS, Node 26.10.0, npm 11.19.1.

`npm run check` = TypeScript 빌드 → 단위 테스트 → 실제 HTTP SDK 클라이언트 스모크.

- 빌드 통과.
- 스케줄러 단위 테스트 11/11 통과. 평일 3요리, 온도 충돌, 추수감사절 8요리, 화구 1개, 오븐 2개, 온도 허용차의 비전이성, 완료 단계 보존, 진행 시작 보존, 충돌 전파, 불가능 입력, 과거 시작 방지 포함.
- 용량 조합 12개 × 지연 요리 8개 = 96회 재계획도 같은 테스트 안에서 검증했다. 배치 함수와 별도로 시간 경계를 순회하는 검증기가 자원 점유·선후 관계·서빙 마감을 검사한다.
- 스모크 통과: initialize → tools/list → 6개 툴 호출, 상태 리소스 읽기, 교체, 오류 시 저장 불변, Origin 차단, SQLite 닫기/다시 열기 뒤 HTTP 조회.
- HTTP 스모크는 임시 포트와 임시 DB를 쓰고 정상/실패 종료 시 정리한다. 실행 중인 사용자 서버에 의존하지 않는다.
- 초기 데모 포함 성공 실행의 19개 툴 호출: 최대 6.24ms, 평균 1.60ms. 후속 실행 최대 6.96ms, 평균 1.76ms. 로컬 단일 실행 수치다.

## 재계획 및 전환 판단

**로컬 D2 관문 통과: One Oven 계속 진행.** Inspector 대신 사용자가 허용한 공식 SDK 스크립트 클라이언트를 사용했다.

스모크에서 3요리 계획을 만들고 `next_step`과 완료 확인을 반복하여 연어 굽기 진행 상태까지 도달했다. `report_delay(plan_id, salmon, 5)` 호출 결과:

- `plan_id` 유지, 버전 증가.
- 서빙 시각 정확히 5분 증가.
- 변경 목록은 `salmon:1`(굽기), `salmon:2`(휴지) 두 단계와 정확히 일치.
- 연어 굽기의 시작 시각, 완료 단계, 밥·그린빈 전체 단계는 그대로 보존.
- 다른 시나리오에서는 화구/손 충돌이 실제로 생길 때만 관련 후속 단계를 이동.

진행 중 단계는 시작을 고정하되 지연 신고 대상의 종료는 늘어난다. 다른 진행/완료 단계와 충돌하면 강제로 움직이지 않고 변경을 거절한다. 재계획은 기존 순서와 시각을 최대한 유지하는 결정적 휴리스틱이며 전역 최소 변경 해법을 증명한 것은 아니다.

## 해석

한 사람이 여러 요리의 손이 필요한 마무리를 동시에 할 수 없으므로, “동시에 완성”은 공통 서빙 시각까지 준비 완료로 구현했다. 요리마다 준비 완료 시각과 추가 대기 분을 표시한다. 무조건 정확히 같은 초에 조리가 끝난다고 주장하지 않는다.

## 실행 방법

```sh
cd one-oven
npm ci
npm run check
npm run dev
# endpoint: http://127.0.0.1:3000/mcp
# 배포용 빌드 실행을 로컬에서 확인하려면:
npm run build
npm start
```

Node 22.13 이상 필요. `PORT`, `DB_PATH`로 포트/SQLite 경로를 바꿀 수 있다.
SDK 클라이언트 사용 예와 전체 호출 흐름은 `scripts/smoke.ts`, 인터페이스/제약은 `README.md` 참조.
