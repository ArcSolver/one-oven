# S3 사람 발화·조리 녹음 확인

상태: **미실행**. 컨테이너의 자동 합성 음성 테스트를 사람 발화나 실제 조리로 간주하지 않는다.

1. `packages/voice/README.md`의 로컬 도구를 설치하고 `npm run dev`, `npm run voice`를 실행한다.
2. 실제 마이크로 주방 설정과 연어·쌀밥·그린빈 3요리 요청을 말한다.
3. `What is next?`, `The rice step is finished`, `The salmon needs five more minutes`로 끝까지 진행한다.
4. 차임과 타이머 안내를 듣고, 안내만으로 다음 단계가 자동 진행되지 않는지 확인한다.
5. `runs/voice-*/user-*.wav`, `voice.jsonl`, `trace.jsonl`을 보관한다. 영상에 쓸 연속 녹음은 OS 오디오 캡처나 별도 녹음기로 만든다.
6. 아래를 채운다. 실제 조리를 함께 했다면 기존 캘리브레이션 문서에도 단계별 시간을 적는다.

| 항목 | 기록 |
| --- | --- |
| 일시·테스터 | 미실행 |
| OS·CPU·마이크·스피커 | 미실행 |
| 배경 소음·마이크 거리 | 미실행 |
| STT 모델·시스템 음성·개발 모델 | 미실행 |
| 최종 서빙 시각·모든 단계 완료 | 미실행 |
| 오인식·재질문·타이머 중복 여부 | 미실행 |
| 실제 발화 종료→첫 소리(오디오 루프백) | 미실행 |
| 녹음·trace 경로 | 미실행 |

합성 WAV 왕복은 인식 회귀 검사이며 부엌 소음, 사람 억양, 물리적 스피커 지연의 검증을 대신하지 않는다.
